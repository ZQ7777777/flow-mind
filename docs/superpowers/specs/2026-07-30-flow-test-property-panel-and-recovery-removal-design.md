# 流程测试页属性栏固定与恢复流转移除设计

## 目标

- 流程定义画布右侧属性栏始终保持固定 `280px` 宽度。
- 属性栏使用固定的视口内可视高度，节点属性超出时仅在属性栏内部纵向滚动。
- 切换不同类型节点时，不改变属性栏和画布区域的布局尺寸。
- 从前端完整移除“终止后恢复流转”能力，不修改任何后端代码或接口。

## 设计

画布三列布局恢复固定的左侧节点栏和右侧属性栏轨道，中央画布继续使用弹性宽度。右侧轨道与 `.property-panel` 同时固定为 `280px`，避免 CSS Grid 根据用户任务字段的固有宽度重新计算列宽。

属性栏高度固定为 `calc(92vh - 210px)`，并保留 `overflow-y: auto`。短属性表单不会缩小面板，长属性表单不会撑高页面，滚动条槽位保持稳定。

前端删除以下恢复流转内容：

- 实例操作区域的“恢复目标节点”下拉框和“恢复流转”按钮。
- `adminRecoverTargetNodeCode` 页面状态。
- `recoverTargetNodes` 计算属性。
- `recoverSelectedInstance` 请求方法。
- 静态页面测试中要求上述内容存在的断言，并增加要求其不存在的回归断言。

保留管理员终止流程、删除实例以及其他实例操作。`API_PATHS.adminJump` 可能被其他跳转场景复用，因此本次仅在确认无其他前端引用时删除；后端实现不做改动。

## 验证

- 静态页面测试先断言固定 `280px` 轨道、固定高度和恢复流转内容不存在。
- 运行 `FlowTestStaticPageTest`。
- 运行 JavaScript 语法检查。
- 在 `platform` 目录运行 `mvn -q test`，记录任何与本次改动无关的既有失败。
