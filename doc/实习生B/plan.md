# 实习生 B：完整运行时实施计划

## 概要

B 覆盖 M0、M1、M2、M3、M4、M5、M6 的运行时职责，按“先定义可发布、再附件可用、后串行流转”的顺序实施，确保通过 11.2。

保留 `platform-core` 与 `platform-starter` 两模块。在 core 内定义 Repository/方言端口，只实现 SQLite；不接入 Oracle/国产数据库驱动，但禁止运行时服务直接写 SQLite 专有 SQL。

## M0：共同契约与运行时边界

- 冻结运行时 DTO、动作结果、状态枚举和错误码；所有状态修改请求必带 `operationId`，任务级请求必带 `expectedTaskVersion`。
- 新增统一 `OperationResult`，删除实例和删除定义不再使用 `void`，以支持幂等重放。
- 冻结回调载荷：`eventId`、动作、实例、归档任务、新建任务、变量快照。
- 定义实例、活动任务、任务组、历史任务的 Repository 端口及 SQLite 实现；B 的服务仅依赖端口。
- 新增 `AttachmentAccessSpi`：附件上传、查看、下载、删除全部交由宿主系统授权；SPI 缺失、调用失败或返回拒绝时一律拒绝操作。C 提供本地 Mock。

## M1：流程定义运行前校验与缓存

- 实现发布前校验引擎：唯一开始节点、至少一个结束节点、连线完整性、无孤立用户任务、审批人规则、表单字段与附件配置去重。
- 将定义、节点、连线解析为不可变运行时图快照；缓存键包含定义 ID 与版本。
- 定义保存、发布、激活、停用、归档、删除后主动失效对应缓存；运行时只读取已发布且激活的快照。
- 与 A 联测：A 负责定义 CRUD 与配置持久化，B 负责校验结果和运行时读取接口。

## M4 前置：附件运行时最小能力

- 在 M2 前完成实例级附件校验与保存编排：读取实例固化的附件配置、校验必填项/格式/大小、调用文件存储 SPI、保存附件元数据。
- 申请节点的银行回单固定为实例级附件；任务级附件保留同一运行时路径，后续节点可按宿主系统授权查看。
- 文件写入后若数据库事务失败，执行最佳努力删除；附件操作权限完全通过 `AttachmentAccessSpi` 决定。
- C 负责文件存储 SPI、附件元数据 Repository 和 Mock；B 负责校验、实例/任务关联、权限调用与事务编排。

## M2：串行运行时闭环

- 实现启动、变量保存、实例创建、申请节点活动任务创建及回调 Outbox 写入。
- 固定 `startAndSubmit` 语义：仅启动并返回申请节点任务；业务适配层再调用 `submitTask` 办理申请节点。
- 实现申请节点提交、历史归档、部门经理任务创建、普通审批、财务确认与办结。
- 所有动作经统一执行器完成：幂等登记、乐观锁 CAS、历史归档、下一任务、任务组、回调日志和结果快照同事务提交。
- CAS 更新失败返回并发冲突；相同 `operationId` 返回第一次结果，同号不同请求拒绝。

## M3 与完整 M4：实例管理、附件管理

- 实现终止、变量更新、实例删除、状态维护；删除时级联清理运行数据，保留审计与回调并标记目标已删除。
- 完成任务级附件、附件列表/下载/删除的运行时接口，所有操作经过宿主授权 SPI。
- 提供 B 的运行时 Service Bean，供 C 的 Starter 自动装配和独立 REST 服务复用。

## M5 与 M6：高级任务状态机

- B 实现驳回、撤回、转办、加签及历史/回调数据；C 负责委托关系、认领/取消认领和查询展示，B 提供其所需状态转换入口。
- 特殊动作采用已确认的保守语义：驳回至已办用户节点；仅发起人可在下游未办理时撤回；加签串行且原任务挂起；转办后原办理人失去办理权。
- 实现会签任务组：创建多任务、`lock_version` CAS 累计、最后一人唯一推进。
- 与 A 的条件/或签配置、C 的并行汇聚实现联测；重复请求或重复分支到达不得重复创建后续任务。

## 协作与验收

| 范围 | B 负责 | 依赖交付 |
|---|---|---|
| M1 | 校验、图解析、定义缓存 | A：定义/节点/连线配置 |
| M4 | 附件校验、关联、权限编排 | C：文件存储、元数据、授权 Mock |
| M2/M3/M5/M6 | 状态机、事务、CAS、历史归档 | A：运行时定义快照；C：幂等、回调、委托与查询 |

- 每个里程碑运行 Maven 单测和 SQLite 集成测试。
- 必测：定义校验与缓存失效、附件授权拒绝与允许、入金串行闭环、并发审批、幂等重放、终止/删除、驳回/撤回/加签/转办、会签最后一人推进。
- 与 C 联测：回调包含归档/新建任务且失败不回滚；Starter 消费方可注入 B 的服务；独立 REST 服务可完成入金申请全链路。
- M0 接口、最小附件/授权 Mock 和定义读取接口未合并前，不进入 M2；灰度、提醒和告警不阻塞 11.2 主线。

## 固定假设s

- 本期不实现 Oracle/国产数据库连接，但当前代码必须具备可替换持久化适配边界。
- 附件权限由宿主系统最终决定，平台默认拒绝未授权或无法判定的请求。
- 流程启动仍采用“启动后办理申请节点”的两次调用链。
