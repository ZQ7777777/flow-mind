## 当前结论

实习生 A 的 M0 代码交付和测试结果已具备阶段冻结基础，可提交 B 线和 C 线联调确认。由于尚未完成 A/B/C 三方联调和签认，本文件当前是 A 线冻结记录草案，不代表最终三方冻结结论。

当前 A 线已形成的冻结内容包括：

- SQLite 17 张业务表、字段、索引、外键、唯一约束和代表性 `CHECK` 约束；
- 流程定义、流程实例、活动任务、任务组、操作记录、回调、催办、告警等状态取值；
- `process_active_task.lock_version` 与 `process_task_group.lock_version` 乐观锁字段；
- 活动任务和任务组的条件更新 Repository；
- 定义状态、实例状态、任务状态、任务组状态、操作状态校验器；
- 流程定义模型结构校验器；
- 与 B/C 线共享的操作号、任务版本、回调事件号和事务一致性约束。

正式三方冻结后，以下变更必须重新评审：

- 表名、字段名、字段类型、默认值、唯一约束、外键或索引变化；
- 状态值新增、删除或重命名；
- 状态迁移规则变化；
- `lock_version` 条件更新规则变化；
- `operation_id`、`event_id`、`expectedTaskVersion`、`TaskDTO.taskVersion` 语义变化；
- Repository 冲突错误码变化。

## 阶段边界

M0 已冻结的是数据、状态和并发基础契约，不包含以下内容：

- 流程定义 CRUD、发布、激活、停用、归档业务服务；
- 实例启动、审批推进、历史归档和完整幂等处理器；
- 条件表达式执行、会签、或签、并行汇聚的完整运行时编排；
- 附件文件读写、外部 SPI、消息回调发送；
- Starter 自动装配、REST Controller、权限校验和参数校验；
- Oracle 或国产数据库适配、正式数据库迁移框架。
