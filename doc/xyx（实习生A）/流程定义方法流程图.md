# 流程定义方法流程图

> 依据代码：`ProcessDefinitionService`、`DefaultProcessDefinitionService`、`ProcessDefinitionRepository`  
> 适用范围：流程定义创建、保存流程图结构、发布、激活、停用、归档、复制、删除、查询、分页查询。

## 1. 方法总览

| 功能 | Service 方法 | 核心状态要求 |
| --- | --- | --- |
| 创建流程定义 | `createDefinition` | 新建为 `DRAFT + INACTIVE + OFF` |
| 保存流程图结构 | `saveGraph` | 仅允许 `DRAFT + INACTIVE + OFF` |
| 发布 | `publish` | `DRAFT + INACTIVE + OFF` -> `PUBLISHED + INACTIVE + OFF` |
| 激活 | `activate` | `PUBLISHED + INACTIVE + OFF` -> `PUBLISHED + ACTIVE + OFF` |
| 停用 | `deactivate` | `PUBLISHED + ACTIVE + OFF` -> `PUBLISHED + INACTIVE + OFF` |
| 归档 | `archive` | `PUBLISHED + INACTIVE + OFF` -> `ARCHIVED + INACTIVE + OFF` |
| 复制 | `copyDefinition` | 复制为同 `processCode` 下一版本草稿 |
| 删除 | `deleteDefinition` | 禁止删除 `ACTIVE` 定义 |
| 查询 | `getDefinition` | 按 `definitionId` 返回完整详情 |
| 分页查询 | `searchDefinitions` | 按查询条件分页返回定义概要 |

## 2. 创建流程定义：`createDefinition`

```mermaid
flowchart TD
    A["收到 CreateProcessDefinitionRequest"] --> B["校验创建请求<br/>operationId、operatorUserId、processCode、processName、systemCode"]
    B --> C["计算创建请求 hash"]
    C --> D["按 DEFINITION_CREATE 开始幂等处理"]
    D --> E{"幂等决策"}
    E -- "REPLAY_SUCCESS" --> F["读取首次成功结果并返回"]
    E -- "CONFLICT / IN_PROGRESS / REPLAY_FAILED" --> G["按幂等语义抛出异常"]
    E -- "NEW / TAKE_OVER" --> H["查询同 processCode 最大 version"]
    H --> I["构造流程定义实体<br/>id=UUID<br/>version=max+1 或 1<br/>DRAFT + INACTIVE + OFF"]
    I --> J["插入 process_definition"]
    J --> K["映射为 ProcessDefinitionDTO"]
    K --> L["标记幂等 SUCCESS<br/>保存 result_json"]
    L --> M["返回 ProcessDefinitionDTO"]
    B -. "校验失败" .-> N["记录确定性失败并抛出"]
    J -. "状态/校验异常" .-> N
```

关键点：

- 客户端不能指定版本号，版本由 `findMaxVersionByProcessCode` 后递增生成。
- 创建成功不写节点、连线、表单字段和附件配置，只创建定义主表草稿。

## 3. 保存流程图结构：`saveGraph`

```mermaid
flowchart TD
    A["收到 definitionId + SaveProcessGraphRequest"] --> B{"definitionId 是否为空"}
    B -- "是" --> X["FLOW_DEFINITION_INVALID"]
    B -- "否" --> C["校验保存请求<br/>operationId、operatorUserId、nodes、edges"]
    C --> D["归一化节点、连线、表单字段、附件配置"]
    D --> E["基于归一化结果计算 SAVE_GRAPH hash"]
    E --> F["按 DEFINITION_SAVE_GRAPH 开始幂等处理"]
    F --> G{"幂等决策"}
    G -- "REPLAY_SUCCESS" --> H["读取首次保存结果并返回"]
    G -- "不可执行" --> I["抛出幂等异常"]
    G -- "NEW / TAKE_OVER" --> J["查询 process_definition"]
    J --> K{"定义是否存在"}
    K -- "否" --> L["FLOW_DEFINITION_NOT_FOUND"]
    K -- "是" --> M["校验可编辑<br/>必须 DRAFT + INACTIVE + OFF"]
    M --> N["校验表单字段和附件配置"]
    N --> O["删除旧连线"]
    O --> P["删除旧节点"]
    P --> Q["批量插入新节点"]
    Q --> R["批量插入新连线"]
    R --> S["刷新定义 updated_by / updated_at"]
    S --> T["保存表单字段"]
    T --> U{"附件配置是否为空"}
    U -- "是" --> V["删除附件配置"]
    U -- "否" --> W["保存草稿附件配置组"]
    V --> Y["重新读取定义并映射 DTO"]
    W --> Y
    Y --> Z["标记幂等 SUCCESS<br/>注册提交后缓存失效<br/>返回 DTO"]
```

关键点：

- 保存采用整图全量替换：先删旧连线，再删旧节点，再插入新节点和新连线。
- 保存只允许草稿、未激活、未灰度的定义。
- 缓存失效通过 `registerGraphCacheInvalidation(definitionId)` 注册到事务提交后执行。

## 4. 发布：`publish`

```mermaid
flowchart TD
    A["收到 DefinitionOperationRequest"] --> B["校验 definitionId、operatorUserId、operationId"]
    B --> C["按 PUBLISH 计算生命周期 hash"]
    C --> D["按 DEFINITION_PUBLISH 开始幂等处理"]
    D --> E{"幂等决策"}
    E -- "REPLAY_SUCCESS" --> F["读取首次生命周期结果并返回"]
    E -- "不可执行" --> G["抛出幂等异常"]
    E -- "NEW / TAKE_OVER" --> H["查询目标定义"]
    H --> I{"定义是否存在"}
    I -- "否" --> X["FLOW_DEFINITION_NOT_FOUND"]
    I -- "是" --> J["校验 gray_status = OFF"]
    J --> K["调用 validateForPublish<br/>执行模型校验"]
    K --> L{"校验是否通过"}
    L -- "否" --> M["FLOW_DEFINITION_INVALID"]
    L -- "是" --> N["Repository 条件更新发布<br/>DRAFT + INACTIVE + OFF -> PUBLISHED + INACTIVE + OFF"]
    N --> O{"影响行数是否为 1"}
    O -- "否" --> P["FLOW_DEFINITION_NOT_EDITABLE"]
    O -- "是" --> Q["重新读取最新定义"]
    Q --> R["写入 process_audit_log"]
    R --> S["标记幂等 SUCCESS"]
    S --> T["注册定义图缓存失效"]
    T --> U["返回发布后的 DTO"]
```

关键点：

- 发布前会通过 `validateForPublish` 校验流程模型。
- 发布成功写审计日志，审计详情记录最新定义状态、激活状态和灰度状态。

## 5. 激活：`activate`

```mermaid
flowchart TD
    A["收到 DefinitionOperationRequest"] --> B["校验请求"]
    B --> C["按 ACTIVATE 计算生命周期 hash"]
    C --> D["按 DEFINITION_ACTIVATE 开始幂等处理"]
    D --> E{"幂等决策"}
    E -- "REPLAY_SUCCESS" --> F["读取首次生命周期结果并返回"]
    E -- "不可执行" --> G["抛出幂等异常"]
    E -- "NEW / TAKE_OVER" --> H["查询目标定义"]
    H --> I["校验 gray_status = OFF"]
    I --> J{"是否 PUBLISHED + INACTIVE"}
    J -- "否" --> X["FLOW_DEFINITION_NOT_EDITABLE"]
    J -- "是" --> K["激活附件草稿配置组"]
    K --> L["查询同 processCode 旧 ACTIVE 全量版本"]
    L --> M["停用同 processCode 下其他 ACTIVE + OFF 版本"]
    M --> N["激活目标定义<br/>activation_status = ACTIVE"]
    N --> O{"影响行数是否为 1"}
    O -- "否" --> P["FLOW_DEFINITION_NOT_EDITABLE"]
    O -- "是" --> Q["收集旧 ACTIVE 定义缓存失效 ID"]
    Q --> R["重新读取最新定义"]
    R --> S["写审计日志"]
    S --> T["标记幂等 SUCCESS"]
    T --> U["注册目标定义缓存失效"]
    U --> V["注册旧 ACTIVE 定义缓存失效"]
    V --> W["返回激活后的 DTO"]
```

关键点：

- 激活会先停用同一 `processCode` 下其他全量激活版本，再激活目标版本。
- 目标版本和旧激活版本的缓存都会失效。

## 6. 停用：`deactivate`

```mermaid
flowchart TD
    A["收到 DefinitionOperationRequest"] --> B["校验请求"]
    B --> C["按 DEACTIVATE 计算生命周期 hash"]
    C --> D["按 DEFINITION_DEACTIVATE 开始幂等处理"]
    D --> E{"幂等决策"}
    E -- "REPLAY_SUCCESS" --> F["读取首次生命周期结果并返回"]
    E -- "不可执行" --> G["抛出幂等异常"]
    E -- "NEW / TAKE_OVER" --> H["查询目标定义"]
    H --> I["校验 gray_status = OFF"]
    I --> J["Repository 条件停用<br/>PUBLISHED + ACTIVE + OFF -> PUBLISHED + INACTIVE + OFF"]
    J --> K{"影响行数是否为 1"}
    K -- "否" --> X["FLOW_DEFINITION_NOT_EDITABLE"]
    K -- "是" --> L["重新读取最新定义"]
    L --> M["写审计日志"]
    M --> N["标记幂等 SUCCESS"]
    N --> O["注册定义图缓存失效"]
    O --> P["返回停用后的 DTO"]
```

关键点：

- 停用只修改激活状态，不删除定义、节点、连线或运行期数据。
- 已经固化了 `definitionId` 的运行中实例不因停用而切换版本。

## 7. 归档：`archive`

```mermaid
flowchart TD
    A["收到 DefinitionOperationRequest"] --> B["校验请求"]
    B --> C["按 ARCHIVE 计算生命周期 hash"]
    C --> D["按 DEFINITION_ARCHIVE 开始幂等处理"]
    D --> E{"幂等决策"}
    E -- "REPLAY_SUCCESS" --> F["读取首次生命周期结果并返回"]
    E -- "不可执行" --> G["抛出幂等异常"]
    E -- "NEW / TAKE_OVER" --> H["查询目标定义"]
    H --> I["校验 gray_status = OFF"]
    I --> J["记录当前归档时间"]
    J --> K["Repository 条件归档<br/>PUBLISHED + INACTIVE + OFF -> ARCHIVED + INACTIVE + OFF"]
    K --> L{"影响行数是否为 1"}
    L -- "否" --> X["FLOW_DEFINITION_NOT_EDITABLE"]
    L -- "是" --> M["重新读取最新定义"]
    M --> N["写审计日志"]
    N --> O["标记幂等 SUCCESS"]
    O --> P["注册定义图缓存失效"]
    P --> Q["返回归档后的 DTO"]
```

关键点：

- 归档要求定义已经发布且未激活。
- 归档会写入 `archived_by` 和 `archived_at`，归档后不可再激活。

## 8. 复制：`copyDefinition`

```mermaid
flowchart TD
    A["收到源 definitionId + CopyProcessDefinitionRequest"] --> B{"definitionId 是否为空"}
    B -- "是" --> X["FLOW_DEFINITION_INVALID"]
    B -- "否" --> C["校验复制请求<br/>operationId、operatorUserId"]
    C --> D["计算 COPY hash"]
    D --> E["按 DEFINITION_COPY 开始幂等处理"]
    E --> F{"幂等决策"}
    F -- "REPLAY_SUCCESS" --> G["读取首次复制结果并返回"]
    F -- "不可执行" --> H["抛出幂等异常"]
    F -- "NEW / TAKE_OVER" --> I["查询源定义"]
    I --> J{"源定义是否存在"}
    J -- "否" --> K["FLOW_DEFINITION_NOT_FOUND"]
    J -- "是" --> L["读取源节点和源连线"]
    L --> M["按同 processCode 查询最大版本并插入新定义<br/>最多重试 3 次版本冲突"]
    M --> N["复制节点并重建主键"]
    N --> O["复制连线并重建主键"]
    O --> P["复制表单字段"]
    P --> Q["复制附件配置"]
    Q --> R["映射新定义 DTO"]
    R --> S["标记幂等 SUCCESS"]
    S --> T["注册新定义缓存失效"]
    T --> U["返回新草稿 DTO"]
```

关键点：

- 复制后的定义固定为 `DRAFT + INACTIVE + OFF`。
- 复制保留业务编码和配置内容，但重建数据库主键。
- 版本冲突时重新读取最大版本并有限重试。

## 9. 删除：`deleteDefinition`

```mermaid
flowchart TD
    A["收到 DefinitionOperationRequest"] --> B["校验 definitionId、operatorUserId、operationId"]
    B --> C["计算 DELETE hash"]
    C --> D["按 DEFINITION_DELETE 开始幂等处理"]
    D --> E{"幂等决策"}
    E -- "REPLAY_SUCCESS" --> F["返回首次删除结果<br/>replayed=true"]
    E -- "不可执行" --> G["抛出幂等异常"]
    E -- "NEW / TAKE_OVER" --> H["查询目标定义"]
    H --> I{"定义是否存在"}
    I -- "否" --> X["FLOW_DEFINITION_NOT_FOUND"]
    I -- "是" --> J{"activation_status 是否 ACTIVE"}
    J -- "是" --> Y["FLOW_DEFINITION_NOT_EDITABLE<br/>禁止删除激活定义"]
    J -- "否" --> K["删除表单字段"]
    K --> L["删除定义附件配置"]
    L --> M["删除运行期附件记录"]
    M --> N["删除已阅记录"]
    N --> O["删除历史任务"]
    O --> P["删除活动任务"]
    P --> Q["删除任务组"]
    Q --> R["删除提醒记录"]
    R --> S["删除告警记录"]
    S --> T["清空审计日志 instance_id 引用"]
    T --> U["清空回调日志 instance_id 引用"]
    U --> V["删除流程实例"]
    V --> W["删除连线"]
    W --> Z["删除节点"]
    Z --> AA["删除流程定义"]
    AA --> AB["标记幂等 SUCCESS<br/>保存 delete result"]
    AB --> AC["注册定义图缓存失效"]
    AC --> AD["返回 OperationResult<br/>deleted=true"]
```

关键点：

- 删除不是逻辑删除，会删除定义期和运行期关联数据。
- 审计日志和回调日志保留，只清空与被删实例相关的 `instance_id` 引用。
- 成功重放返回首次删除结果，不重复执行级联删除。

## 10. 查询：`getDefinition`

```mermaid
flowchart TD
    A["收到 definitionId"] --> B{"definitionId 是否为空"}
    B -- "是" --> X["IllegalArgumentException"]
    B -- "否" --> C["查询 process_definition"]
    C --> D{"定义是否存在"}
    D -- "否" --> E["返回 null"]
    D -- "是" --> F["查询节点列表"]
    F --> G["查询连线列表"]
    G --> H["查询表单字段"]
    H --> I["查询附件配置"]
    I --> J["组装 ProcessDefinitionDetailDTO"]
    J --> K["返回完整定义详情"]
```

关键点：

- 查询详情不做幂等处理，因为它是只读方法。
- 返回内容包含定义主信息、节点、连线、表单字段和附件配置。

## 11. 分页查询：`searchDefinitions`

```mermaid
flowchart TD
    A["收到 ProcessDefinitionQuery"] --> B["规范化查询条件<br/>pageNo、pageSize、状态枚举等"]
    B --> C["按条件 countByQuery 统计总数"]
    C --> D["按条件 searchByQuery 查询当前页"]
    D --> E["排序规则<br/>updated_at DESC<br/>process_code ASC<br/>version DESC"]
    E --> F["逐条映射为 ProcessDefinitionDTO"]
    F --> G["组装 PageResult"]
    G --> H["设置 records、pageNo、pageSize、total、totalPages"]
    H --> I["返回分页结果"]
```

关键点：

- Repository 支持按 `processCode`、`processName`、`systemCode`、定义状态、激活状态、灰度状态过滤。
- 默认分页参数由查询规范化逻辑处理；总页数按 `ceil(total / pageSize)` 计算。
