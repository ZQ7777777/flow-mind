# 实习生 A：M2 运行时协作编码计划

版本：v1.0  
修订日期：2026-07-22  
阶段：M2 运行时闭环  
负责人：实习生 A（徐雨新）  
参考文档：《流程平台技术路线 v5.2》《实习生 B：M2 运行时编码计划》《流程平台设计与接口文档 v4》  
技术基线：Java 8、Spring Boot 2.7.18、Spring JDBC、SQLite

## 1. 阶段目标

M2 阶段 A 线负责为 B 线运行时闭环提供“节点配置读取”和“审批规则解析协作”能力。A 不实现 `ProcessRuntimeService` 主流程，不接管任务创建、任务乐观锁、历史任务归档、运行时幂等、回调 Outbox 或附件运行时管理。

M2 完成后，B 线可以从完整流程定义快照中稳定读取节点、连线、审批规则、网关配置和条件表达式，并通过 A 线提供的组件构造 `ApproverResolveRequest` 或判断排他网关出线条件。

## 2. 已明确决策

1. `APPROVER_EXPRESSION` 在 M2 只做配置解析和透传给 `ApproverResolver`，A 线不对它做表达式求值。
2. 条件表达式指 `process_edge.condition_expression` / `ProcessEdgeDTO.conditionExpression`，用于排他网关判断流程走哪条连线。
3. M2 条件表达式限定为简单比较，复杂表达式、函数调用、脚本执行、嵌套逻辑留到后续阶段。
4. A 线只提供可复用组件和测试，不新增业务概念，不硬编码入金申请规则。

## 3. 范围边界

### A 线 M2 负责

- 复用或抽取运行时可用的只读流程图索引。
- 提供节点运行配置读取能力。
- 解析节点审批规则 JSON，构造 `ApproverResolveRequest`。
- 提供简单条件表达式求值组件，服务排他网关选路。
- 明确 M2 不支持的表达式和节点配置错误码。
- 补充单元测试和必要集成测试。

### A 线 M2 不负责

- 不实现 `startProcess`、`startAndSubmit`、`submitTask`、`approve` 等运行时 Service 主流程。
- 不实现活动任务 CAS、任务组汇聚 CAS、历史任务归档。
- 不实现附件上传、下载、附件模板运行时校验或文件存储。
- 不实现回调 Outbox、审计日志、查询服务或 Starter 自动装配。
- 不实现发布、激活、停用、归档、灰度发布状态治理。
- 不实现或签、会签、嵌套并行、复杂表达式引擎。

## 4. 编码任务

### M2-A1：运行时只读流程图索引

开发内容：

1. 复核 `DefinitionGraphIndex` 当前可见性和能力。
2. 将校验器与运行时都需要的索引能力抽取为内部只读对象，避免 B 线重复解析节点和连线。
3. 支持按节点编码查询节点、按源节点查询有序出线、按目标节点查询入线、查找唯一开始节点、查找结束节点。
4. 出线排序固定为 `sortOrder, edgeCode`，保证条件网关命中顺序稳定。
5. 索引对象只读，不修改 DTO。

完成标准：

- B 线可通过该索引完成节点推进读取。
- 原有 `DefinitionModelValidator` 测试不回退。
- 新增测试覆盖节点查询、出线排序、缺失节点、重复编码防护。

### M2-A2：节点运行配置读取

开发内容：

1. 新增或扩展节点配置读取组件，例如 `RuntimeNodeConfigReader`。
2. 从 `ProcessDefinitionDetailDTO` 读取以下配置：
   - 节点类型；
   - 审批规则类型；
   - 审批规则 JSON；
   - 多实例模式；
   - 配对网关编码；
   - 监听、超时、提醒配置；
   - 坐标和排序只作为定义展示信息，不参与运行时判断。
3. 对运行时必须字段做轻量校验，返回稳定错误，不抛随机 JSON 解析异常。
4. 不在读取组件里访问数据库或调用 SPI。

完成标准：

- 用户任务、开始节点、结束节点、排他网关、并行网关配置都能稳定读取。
- 非法 JSON、缺失规则、错误节点类型有测试覆盖。

### M2-A3：审批规则解析请求构造

开发内容：

1. 提供审批人解析请求构造组件，例如 `ApproverResolveRequestFactory`。
2. 输入为流程定义快照、实例上下文、当前节点、流程变量、发起人信息。
3. 输出为 `ApproverResolveRequest`，包含：
   - `definitionId`；
   - `instanceId`；
   - `nodeCode`、`nodeName`；
   - `approverRuleType`；
   - 解析后的 `approverRuleConfig`；
   - 发起人和变量上下文。
4. `APPROVER_EXPRESSION` 只校验配置 JSON 合法并透传表达式内容，不做表达式求值。
5. `STARTER` 规则由请求构造阶段保留明确语义，最终候选人仍由 B 线运行时或 `ApproverResolver` 使用。

完成标准：

- `USER`、`DEPARTMENT`、`ROLE`、`ROLE_IN_DEPARTMENT`、`STARTER`、`APPROVER_EXPRESSION` 均有构造测试。
- `APPROVER_EXPRESSION` 测试明确断言表达式原样进入 `ApproverResolveRequest`。
- 缺失必要配置时返回稳定错误。

### M2-A4：简单条件表达式求值

开发内容：

1. 新增条件表达式求值端口，例如 `ConditionExpressionEvaluator`。
2. M2 仅支持简单比较：
   - `amount > 100000`
   - `amount >= 100000`
   - `amount < 100000`
   - `amount <= 100000`
   - `accountType == "company"`
   - `urgent == true`
   - `status != "REJECTED"`
3. 支持变量类型：
   - 数字；
   - 字符串；
   - 布尔值。
4. 明确不支持：
   - `&&`、`||`；
   - 括号；
   - 函数调用；
   - 脚本执行；
   - 集合访问；
   - 跨对象属性链。
5. 表达式为空由 B 线按默认线处理；非默认线表达式为空应在发布校验中拒绝。
6. 求值异常返回稳定错误，不能吞掉后走默认线。

完成标准：

- 简单数字、字符串、布尔比较均有测试。
- 变量缺失、类型不匹配、复杂表达式、非法语法均有测试。
- 不引入第三方脚本引擎。

### M2-A5：与 B 线运行时对接

开发内容：

1. 向 B 线提供清晰调用方式：
   - 运行时加载定义快照；
   - 构建只读图索引；
   - 读取当前节点配置；
   - 构造审批人解析请求；
   - 对排他网关连线条件求值。
2. B 线负责调用 `ApproverResolver.resolveApprovers(request)` 并处理候选人为空、SPI 异常和权限判断。
3. B 线负责 `ProcessRuntimeService` 的事务、幂等、任务 CAS、历史任务、后续节点推进。
4. A/B 联调时优先使用正式接口 Fake，不在生产代码加入临时实现。

完成标准：

- B 线无需重复解析审批规则 JSON。
- B 线无需重复写条件表达式求值逻辑。
- 接口边界不依赖入金申请业务字段。

### M2-A6：测试与文档收口

开发内容：

1. 新增单元测试：
   - 只读图索引；
   - 节点配置读取；
   - 审批规则请求构造；
   - 条件表达式求值。
2. 新增必要集成测试，验证入金申请定义中的申请、部门经理、财务确认节点配置可被读取。
3. 运行测试：
   - `mvn -q -pl platform/platform-core -am test`
   - `mvn -q test`，执行目录为 `platform`
4. 更新 M2 实现记录：
   - `技术实现说明.md`
   - `阶段完成记录.md`
   - 测试结果记录

完成标准：

- A 线组件测试通过。
- 现有 M0/M1 定义管理、发布校验、缓存测试不回退。
- 文档记录已落地能力和未纳入范围。

## 5. 建议执行顺序

```text
M2-A1 只读流程图索引
  -> M2-A2 节点运行配置读取
  -> M2-A3 审批规则解析请求构造
  -> M2-A4 简单条件表达式求值
  -> M2-A5 与 B 线运行时对接
  -> M2-A6 测试与文档收口
```

## 6. 验收清单

- [ ] 运行时可复用只读流程图索引。
- [ ] 节点配置读取不访问数据库、不调用 SPI。
- [ ] `APPROVER_EXPRESSION` 只透传给 `ApproverResolver`，A 线不求值。
- [ ] 审批规则 JSON 解析错误有稳定错误。
- [ ] 条件表达式只支持简单比较。
- [ ] 复杂表达式被明确拒绝。
- [ ] 排他网关出线求值顺序稳定。
- [ ] B 线可以复用 A 的组件完成用户任务候选人解析前置构造。
- [ ] 入金申请串行流程节点配置可读取。
- [ ] `mvn -q test` 在 `platform` 目录通过。

## 7. 风险与处理

| 风险 | 处理 |
| --- | --- |
| A 线提前实现审批人表达式求值，和 M4 SPI 重叠 | M2 固定只构造 `ApproverResolveRequest` 并透传 `APPROVER_EXPRESSION` |
| 条件表达式范围膨胀成脚本引擎 | M2 只支持简单比较，不支持函数、逻辑组合和脚本执行 |
| B 线重复解析流程图 | A 线提供可复用只读索引和节点配置读取组件 |
| 配置读取组件承担运行时事务职责 | A 线组件保持纯读取/纯解析，不写库、不提交事务 |
| 表达式异常导致错误走默认线 | 非默认线表达式异常直接返回稳定错误，由 B 线回滚运行时事务 |

## 8. 后续阶段说明

复杂表达式、审批人表达式求值、组织架构深度解析、或签、会签和嵌套并行不纳入 A 线 M2。后续如需要增强，应在 M4/M5/M6 结合 SPI、权限和运行时事务统一设计。
