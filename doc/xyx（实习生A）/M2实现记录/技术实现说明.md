# 实习生 A：M2 技术实现说明

阶段：M2 运行时协作  
更新日期：2026-07-22  
范围：节点配置读取、审批规则解析请求构造、简单条件表达式求值。

## 已落地能力

1. `DefinitionGraphIndex` 已开放为运行时可复用只读流程图索引：
   - 支持按节点编码读取节点；
   - 支持按连线编码读取连线；
   - 支持读取有序出线、入线、开始节点、结束节点和网关节点；
   - 出线排序沿用 `sortOrder, edgeCode`，保证排他网关选路顺序稳定。

2. 新增 `RuntimeNodeConfigReader`：
   - 从 `ProcessDefinitionDetailDTO` 读取节点运行配置；
   - 解析 `approverRuleConfig`、`listenerConfig`、`timeoutConfig`、`reminderConfig` JSON；
   - 只读定义快照，不访问数据库，不调用 SPI，不承担事务职责；
   - 对非法 JSON、缺失用户任务审批规则、缺失 `APPROVER_EXPRESSION.expression` 返回稳定错误。

3. 新增 `ApproverResolveRequestFactory`：
   - 基于定义快照、实例 ID、节点编码、发起人和变量构造 `ApproverResolveRequest`；
   - `APPROVER_EXPRESSION` 只解析配置并透传 `expression`，A 线不做表达式求值；
   - 最终审批人解析仍由 B 线运行时调用 `ApproverResolver` 完成。

4. 新增 `ConditionExpressionEvaluator` 与 `SimpleConditionExpressionEvaluator`：
   - M2 仅支持简单比较；
   - 支持数字、字符串、布尔值；
   - 支持 `>`、`>=`、`<`、`<=`、`==`、`!=`；
   - 明确拒绝 `&&`、`||`、括号、函数调用、脚本执行、集合访问和属性链。

## 关键边界

- A 线不实现 `ProcessRuntimeService`。
- A 线不创建活动任务、不归档历史任务、不处理任务乐观锁。
- A 线不实现附件运行时校验、回调 Outbox、查询服务或 Starter 自动装配。
- 复杂条件表达式和审批人表达式求值留到后续阶段结合 SPI 统一设计。

## 测试覆盖

新增测试：`RuntimeDefinitionConfigurationTest`。

覆盖点：

- 运行时包可复用 `DefinitionGraphIndex`；
- 排他网关出线按稳定顺序读取；
- 节点配置 JSON 可解析；
- 非法审批规则 JSON 返回稳定错误；
- `APPROVER_EXPRESSION` 原样透传；
- 缺失 `expression` 字段返回稳定错误；
- 简单条件表达式支持数字、字符串、布尔比较；
- 复杂表达式、变量缺失和函数调用被拒绝。
