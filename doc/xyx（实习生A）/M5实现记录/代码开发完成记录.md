# 实习生 A：M5 代码开发完成记录

更新日期：2026-07-28

## 1. 完成结论

经对 M5 要求、生产代码和测试文件逐项审查，实习生 A 的 M5 阶段代码开发已经完成，完成范围限定为 A 线职责：增强规则配置的保存、复制、查询保真、发布前冻结校验，以及提供给 B/C 线消费的稳定配置读取边界。

M5 仍不交付 `OR_SIGN`、`COUNTERSIGN` 的运行时任务组闭环，也不接管驳回、撤回、转办、加签、委托代办、认领、审计、已阅、提醒等 B/C 线运行能力。

## 2. 已完成内容

### 2.1 节点监听配置冻结

- 新增 `NodeListenerConfigReader`，校验 `listenerConfig` 根对象和 `listeners` 数组结构。
- 节点监听事件白名单冻结为 `TASK_CREATED`、`TASK_COMPLETED`。
- 处理器标识按当前 M5 本地注册标识白名单校验：`workflowCallbackHandler`、`recordingWorkflowCallbackHandler`、`callback`。
- 监听项支持 `eventType/event`、`handlerId/handler`、`failureStrategy`、`params`，并拒绝未冻结字段。
- 保留兼容读取 `onCreate`、`onComplete` 旧式 handler 标识。
- 不在定义保存或发布校验阶段执行监听器。

### 2.2 `listenerConfig.taskActionRules` 规则承载

- `listenerConfig` 继续承载 `taskActionRules`，未新增 `action_rule_config` 字段，未新增动作规则表。
- `TaskActionRuleConfigReader` 解析：
  - `reject.enabled`
  - `reject.targetNodeCodes`
  - `directSend.enabled`
  - `directSend.targetMode=REJECT_SOURCE`
- `EnhancedTaskActionCoordinator` 已通过 `TaskActionRuleConfigReader` 读取驳回/直送规则，避免运行层直接散落解析原始 JSON Map。

### 2.3 条件表达式配置冻结

- `ConditionExpressionSyntaxValidator` 提供发布期语法解析。
- M5 仅支持单变量简单比较：
  - 数字比较，例如 `amount > 100000`
  - 字符串等值比较，例如 `accountType == "company"`
  - 布尔等值比较，例如 `urgent == true`
- 拒绝脚本、函数、括号、逻辑组合和不受限表达式。
- `DefinitionModelValidator` 校验条件表达式只能配置在排他网关的非默认出线上。

### 2.4 会签/或签配置冻结

- `ProcessNodeDTO.multiInstanceMode` 保留 `SINGLE`、`OR_SIGN`、`COUNTERSIGN`。
- `DefinitionModelValidator` 允许用户任务配置 `OR_SIGN`、`COUNTERSIGN`。
- 非用户任务显式配置 `OR_SIGN`、`COUNTERSIGN` 会被发布校验拦截；非用户任务上的默认 `SINGLE` 视为无多人审批配置，不阻断发布。
- `OR_SIGN`、`COUNTERSIGN` 发布前会校验审批人规则至少包含可静态证明的选择器：
  - `USER`：`userIds` 至少一个非空值
  - `DEPARTMENT`：`departmentId` 非空
  - `ROLE`：`roleCode` 非空
  - `ROLE_IN_DEPARTMENT`：`roleCode` 非空，部门上下文可由运行时发起人部门补齐
  - `APPROVER_EXPRESSION`：`expression` 非空
  - `STARTER`：视为可解析
- 实际组织数据是否解析为空仍由运行时 `ApproverResolver` 和运行时请求校验兜底。

### 2.5 保存、复制、查询和幂等保真

- `DefinitionGraphDraftFactory.normalizeNodes` 保留并归一化 `multiInstanceMode`、`listenerConfig`。
- `DefinitionGraphDraftFactory.normalizeEdges` 保留 `conditionExpression`。
- 定义复制逻辑保留 `multiInstanceMode`、`listenerConfig`、`conditionExpression`。
- `ProcessDefinitionMapper` 在 DTO 与实体之间双向映射上述 M5 字段。
- `DefaultProcessDefinitionService.hashSaveGraph` 已纳入 `multiInstanceMode`、`listenerConfig`、`conditionExpression`，避免同一 `operationId` 下不同 M5 配置被误判为同一请求。
