# 实习生 C：M6 阶段代码交付记录

## 已实现

1. 管理员运行数据查询
   - `DefaultAdminProcessService.queryInstances`
   - `DefaultAdminProcessService.queryActiveTasks`
   - `DefaultAdminProcessService.queryHistoryTasks`
   - Repository 分页与 count：`ProcessInstanceRepository`、`ActiveTaskRepository`、`ProcessHistoryTaskRepository`

2. 管理员修复治理
   - 新增 `AdminPermissionGuard`，默认管理员用户：`admin`、`operator`、`system_timeout`
   - `jumpToNode`、`forceComplete` 增加管理员权限校验
   - 管理员修复审计优先使用 `AuditLogWriter`
   - 状态类平台异常通过 `ActionExceptionAlertWriter` 生成 `ACTION_EXCEPTION` 告警

3. 任务组诊断
   - 新增 `TaskGroupViewDTO`
   - `TaskGroupRepository.findByInstanceId`
   - `AdminProcessService.queryTaskGroups`
   - REST：`GET /api/platform/admin/instances/{instanceId}/task-groups`

4. 节点级超时策略
   - 新增 `TimeoutPolicy`、`TimeoutPolicyReader`、`TimeoutDueDateCalculator`
   - `RuntimeNodeAdvancer.createActiveTask` 根据用户任务节点 `timeoutConfig` 自动写入 `dueAt`
   - 最小 JSON 字段：`enabled`、`durationMinutes`、`severity`、`action`、`targetNodeCode`

5. 自动提醒与超时动作
   - 新增 `ReminderPolicy`、`ReminderPolicyReader`、`ReminderDeduplicationGuard`
   - `scanTimeoutTasks` 保持 dry-run 只读；非 dry-run 根据策略写提醒、告警或触发自动动作
   - 自动动作支持 `ALERT`、`REMIND`、`JUMP`、`TERMINATE`、`FORCE_COMPLETE`
   - 自动跳转/强制办结复用 `AdminProcessService`，自动终止复用 `ProcessRuntimeService`

6. 回调失败与告警闭环
   - 新增 `CallbackDispatchService.dispatchPending(limit)`
   - 新增 `CallbackFailureAlertService`
   - 回调投递失败会 mark failed，并按 `eventId` 去重生成 `CALLBACK_FAILED` 告警

7. REST 入口
   - `GET /api/platform/admin/instances`
   - `GET /api/platform/admin/tasks`
   - `GET /api/platform/admin/history-tasks`
   - `GET /api/platform/admin/instances/{instanceId}/task-groups`
   - `POST /api/platform/admin/instances/{instanceId}/jump`
   - `POST /api/platform/admin/instances/{instanceId}/force-complete`
   - `POST /api/platform/admin/callback-dispatch`

## 边界说明

- 并行拆分和汇聚核心推进逻辑未重写，仍由 `RuntimeNodeAdvancer` 和 `TaskGroupRepository.markBranchArrived` 承担。
- A 线条件/或签、B 线会签运行逻辑未在本次修改中扩展。
- 管理员权限首期采用可替换的最小 Guard；真实角色、租户和权限 SPI 后续可替换该组件。
- 超时策略为 M6 最小可验收 JSON，不包含工作日历、节假日和复杂升级链路。
