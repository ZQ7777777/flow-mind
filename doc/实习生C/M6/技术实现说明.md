# 实习生 C M6 技术实现说明

更新时间：2026-07-29

## Starter 接线

`PlatformAutoConfiguration` 现已直接装配 M6 真实组件：

- `ProcessNodeRepository`、`ProcessCallbackLogRepository`
- `TimeoutPolicyReader`、`ReminderPolicyReader`、`ReminderDeduplicationGuard`
- `AdminPermissionGuard`、`ActionExceptionAlertWriter`
- `CallbackLogMapper`、`CallbackOutboxService`、`DefaultCallbackService`
- `CallbackFailureAlertService`、`CallbackDispatchService`

`ProcessMonitorService` 改用 `DefaultProcessMonitorService` 的完整构造器，节点级超时与提醒策略不再因兼容构造器而退化为空依赖。宿主同时提供 `AdminProcessService` 和 `ProcessRuntimeService` 时，Starter 通过条件装配创建 `TimeoutActionExecutor`，用于 `JUMP`、`TERMINATE` 和 `FORCE_COMPLETE`。所有新增 Bean 均保留 `@ConditionalOnMissingBean`，允许宿主替换。

外部 `MessagePublisher` 或 `WorkflowCallbackHandler` 缺失时，Starter 仍能启动，但实际发送或投递时失败关闭并报告缺失 SPI，避免静默丢消息。

## SQLite 验收链路

`M6OrSignConcurrencyIntegrationTest` 使用文件型 SQLite、WAL 和两个独立连接，在同一起跑闩锁后以相同任务组版本竞争 `completeOrSignGroup`。测试断言只有一个更新成功，最终组状态为 `COMPLETED`，锁版本仅从 0 增至 1。

`M6AdvancedFlowCrossLineSqliteIntegrationTest` 复用生产定义服务、运行时服务和 Repository，执行以下链路：

```text
开始 → 发起人任务 → 排他条件 → 或签 → 会签
     → 并行拆分 → 两分支审批 → 并行汇聚
     → 超时任务告警 → 办结 → 回调投递失败告警
```

关键断言包括：

- 金额条件命中或签路径；
- 或签创建两条任务，赢家完成后兄弟任务取消；
- 会签首人完成不推进，末人完成后唯一进入并行拆分；
- 两个并行分支全部到达后只创建一个汇聚后任务；
- 节点 `timeoutConfig` 生成 `due_at`，非 dry-run 扫描生成去重的 `TASK_TIMEOUT` 告警；
- 流程最终完成，三个任务组均为 `COMPLETED`；
- 回调处理器异常会把本实例 Outbox 标记为 `FAILED` 并生成 `CALLBACK_FAILED` 告警。

测试对自有流程数据执行前置和后置清理；回调投递窗口只选择本用例提前排序的确切待处理数量，避免消费共享测试库中的其他实例。

## 测试结果

```powershell
mvn -q -pl platform/platform-starter -am "-Dtest=PlatformAutoConfigurationTest,M6AdvancedFlowCrossLineSqliteIntegrationTest,M6OrSignConcurrencyIntegrationTest" "-Dsurefire.failIfNoSpecifiedTests=false" test
mvn -q clean test
```

结果：76 个测试套件、490 项测试，0 失败、0 错误、0 跳过。

独立子 agent 审查未发现 P0。审查提出的共享 SQLite 回调误消费风险、测试后置清理、Starter 跳转请求字段断言和重复 import 均已修正。

## 保留边界

- Starter 不复制 A/B 线状态机；自动动作继续委托唯一的 `AdminProcessService` 和 `ProcessRuntimeService`。
- 或签并发新增测试聚焦 Repository 原子 CAS；运行时兄弟任务取消由跨线测试与既有 `DefaultProcessRuntimeServiceTest` 覆盖。
- M6 超时策略仍是自然分钟级最小策略，不包含工作日历、节假日或复杂升级链。
