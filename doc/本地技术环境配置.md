# 本地技术环境配置

## 仓库已提供的项目配置

`git clone` 后只能获得以下项目级配置，不能自动安装本机 JDK、Maven、SQLite CLI 等系统工具。

- Maven 多模块工程：`platform-api`、`platform-core`、`platform-persistence`、`platform-starter`、`platform-web`、`platform-mock`、`platform-demo`。
- Java 编译级别：Java 8。
- Spring Boot：`2.7.18`。
- 持久化方案：Spring JDBC。
- SQLite JDBC 驱动：`org.xerial:sqlite-jdbc:3.42.0.0`。
- 测试依赖：JUnit 5 / Spring Boot Test。
- Starter 自动装配入口：`platform-starter/src/main/resources/META-INF/spring.factories`。
- Demo 启动类：`platform-demo/src/main/java/com/flowmind/platform/demo/PlatformDemoApplication.java`。
- 项目级 Maven 配置：`.mvn/settings.xml` 将依赖缓存放在仓库内 `.m2/repository`，避免使用机器上的全局 Maven 安装目录。

## 合作人本机仍需准备

每位合作人 clone 仓库后，还需要确认本机已具备：

- JDK 8，并且 `java -version` 输出 1.8。
- Maven 3.5+，并且 `mvn -version` 能正常输出。
- 可访问 Maven 镜像仓库，用于首次下载 Spring Boot、SQLite JDBC 等依赖。
- 可选：SQLite CLI。应用运行依赖 SQLite JDBC，不强制依赖 `sqlite3` 命令；只有手动查看数据库文件时才需要 SQLite CLI。

## 手动安装 SQLite CLI

SQLite JDBC 驱动已经在 Maven 依赖中声明，应用运行不依赖本机 `sqlite3` 命令。但如果要手动查看、导出、检查数据库文件，需要安装 SQLite CLI。

1. 打开 SQLite 下载页：`https://www.sqlite.org/download.html`。
2. 下载 Windows 预编译工具包，文件名通常类似 `sqlite-tools-win-x64-*.zip`。
3. 解压到固定目录，例如 `E:\tools\sqlite`。
4. 将该目录加入系统环境变量 `Path`。
5. 重新打开 PowerShell，执行：

```powershell
sqlite3 --version
```

能输出版本号即安装完成。

## 本地验证命令

```powershell
.\scripts\check-env.ps1
mvn -version
mvn -DskipTests package
```

如果 `mvn -DskipTests package` 首次执行失败且提示无法下载依赖，说明当前环境无法访问 Maven Central，需要配置 Maven 镜像或在有网络环境下预先下载依赖。

## Maven 镜像配置

本仓库已经提供项目级 Maven 配置：`.mvn/settings.xml`。

如果你希望改成用户级配置，可编辑 `%USERPROFILE%\.m2\settings.xml`，加入：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyunmaven</id>
      <mirrorOf>central</mirrorOf>
      <name>Aliyun Maven</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```
