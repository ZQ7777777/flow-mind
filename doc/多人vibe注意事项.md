# 注意事项
### 1. 统一代码规范
包括（技术栈、注释、风格），可考虑写在项目根文件的AGENTS.md中
### 2. 文档驱动
- README.md：项目概述和使用说明
- CONTRIBUTING.md：如何参与开发
- CODE\_STYLE.md：代码规范
- API.md：API 接口文档
- CHANGELOG.md：版本更新记录
### 3. git分支
从 develop 分支创建 feature 分支;在 feature 分支上开发，开发完成后提交 Pull Request;经过审查后合并到 develop;定期将 develop 合并到 main
### 4. CR
审查这段代码，从功能、性能、安全、代码质量等角度分析：【贴上代码】
### 5. Skills
特定规则不放在AGENTS.md中，写成skill以节省上下文；长参考材料（比如需求文档）放在Skill supporting files
